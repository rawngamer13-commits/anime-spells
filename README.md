# Anime Spells Mod

Un mod para **Minecraft 1.12.2** que añade hechizos inspirados en anime a **Electroblob's Wizardry**.

## Características

### Hechizo: Doom
Inspirado en **Frieren: Beyond Journey's End**

- 🌌 Crea un agujero negro devastador
- 🔴 Bordes rojo-dorados brillantes
- 🌅 El cielo se vuelve rojo carmesí en el área
- ⚫ Absorbe y atrae todas las entidades cercanas
- ⚡ Inflige daño progresivo
- 📖 Se añade automáticamente al libro de hechizos de Wizardry
- 🔨 Se encanta en la mesa de magia (Wizard's Workbench)

## Requisitos

- **Minecraft 1.12.2**
- **Forge 1.12.2** (14.23.5.2860 o superior)
- **Electroblob's Wizardry 4.3.0** (o compatible)

## Instalación

1. Descarga el archivo `.jar` compilado
2. Colócalo en tu carpeta `mods` de Minecraft
3. Abre Minecraft con Forge instalado
4. ¡Disfruta los nuevos hechizos!

## Uso

1. Obtén un libro de hechizos con el hechizo Doom
2. Usa la **Wizard's Workbench** para encantarlo en una varita maestra
3. ¡Lanza el hechizo y observa cómo el mundo se tiñe de rojo!

## Futuro

Se planean agregar más hechizos de anime en futuras actualizaciones.
